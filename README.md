### 1. Deskripsi Proyek
Aplikasi ini menggunakan teknologi **Python Multiprocessing** untuk melakukan perhitungan kalkulasi data berskala besar (10 Juta data) secara paralel. Proyek ini terintegrasi sebagai modul pemrosesan data cepat untuk mendukung fungsionalitas sistem CuffnCode.

### 2. Implementasi Komputasi Paralel
* **Teknologi:** Python `multiprocessing.Pool`
* **Metode:** Beban komputasi dibagi rata ke seluruh core CPU yang tersedia di perangkat secara bersamaan (paralel), sehingga memangkas waktu eksekusi dibandingkan metode sekuensial.

### 3. Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Jalankan perintah di terminal: `python tugas.py`

### 4. Demo & Evaluasi
* **Video Demonstrasi:** Sudah diunggah ke Instagram Lab.
* **Hasil:** Program berhasil memproses 10,000,000 data secara paralel dengan performa yang optimal memanfaatkan core hardware laptop.
